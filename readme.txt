SKLADOVA NALICHNOST - PYTHON PROEKT

Opisanie:
Tova e Python proekt za upravlenie na skladova nalichnost napraven ot Aleks Angelov

Failove:
- models.py
- main.py
- requirements.txt
- readme.txt

Biblioteki:
- colorama

Startirane:
1. Instalirai bibliotekite:
python3 -m pip install -r requirements.txt

2. Startirai programata:
python main.py

Funkcii:
- dobavyane na produkt
- premahvane na produkt
- tarsene na produkt
- pokazvane na produkti

Izpolzvani sa:
- klasove
- obekti
- self
- metodi
- cikli
- uslovni operatori
